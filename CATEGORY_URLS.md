# Portfolio Category Page URLs

## Available Category Pages

Visit these URLs to see the category-specific portfolio pages:

### 1. Website & Web Application Projects
**URL:** `/portfolio/website-and-web-application-projects`
- Shows all web development projects
- Custom web platforms, SaaS applications, enterprise portals

### 2. Mobile App Projects
**URL:** `/portfolio/mobile-app-projects`
- Shows all mobile application projects
- Native iOS, Android, and cross-platform apps

### 3. Digital Marketing Projects
**URL:** `/portfolio/digital-marketing-projects`
- Shows all digital marketing campaigns
- SEO, PPC, social media marketing projects

### 4. Branding & Graphic Design
**URL:** `/portfolio/branding-and-graphic-design`
- Shows all branding and design work
- Logo design, brand identities, visual systems

### 5. Videography & Photography
**URL:** `/portfolio/videography-and-photography`
- Shows all video and photo production
- Commercial videos, photography, visual content

## Features on Each Category Page

✅ **Navbar** - Full navigation menu
✅ **Banner** - Category-specific hero image
✅ **Category Info** - Description, icon, and stats
✅ **Stats Grid** - Key metrics (3 stat cards)
✅ **Projects Grid** - Filtered projects in responsive grid
✅ **FAQ Section** - 5 relevant questions with accordion
✅ **CTA Section** - Call-to-action with dual buttons
✅ **Footer** - Complete footer with links

## How to Navigate

From the main portfolio page (`/portfolios`), you can:
1. Click on any category filter button
2. Hover over the button to see "View Category →" link
3. Click the link to navigate to the dedicated category page

## All Pages Are Fully Responsive

- **Mobile** (< 640px): Single column, stacked layout
- **Tablet** (640-1024px): 2 columns for projects
- **Desktop** (> 1024px): 3 columns for optimal viewing
